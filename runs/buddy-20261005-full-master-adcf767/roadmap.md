# Roadmap

- ARCH-P1-001 (P1) — Client is fully authoritative: no server trust boundary exists
- BP-P1-001 (P1) — master is unprotected: no required PR, review, or status checks
- BP-P1-002 (P1) — The `release` environment required by release.yml does not exist
- CI-P1-001 (P1) — CI is failing on master at the audited commit
- ARCH-P2-001 (P2) — Inventory item actions mutate the store but are never persisted
- CI-P2-001 (P2) — dependency-review job is skipped because the dependency graph / Dependabot is disabled
- DATA-P2-001 (P2) — Inventory item actions are not written to the save
- DOC-P2-001 (P2) — README states the stack is Next.js 14 but the repo is Next.js 15.5.27
- DOC-P2-002 (P2) — README 'Known gaps' and testing sections contradict the current code/tests
- DR-P2-001 (P2) — No backup/restore drill and no committed evidence of one
- FILE-P2-001 (P2) — Save export uses btoa and can throw on non-Latin-1 content
- SC-P2-001 (P2) — High-severity postcss advisory remains in the production dependency tree (accepted)
- SC-P2-002 (P2) — Repository secret-scanning and Dependabot security updates are disabled
- SC-P2-003 (P2) — Vendored prompt pack authorship and licensing are unconfirmed
- SEC-P2-001 (P2) — CSP allows 'unsafe-inline' scripts and styles
- USE-P2-001 (P2) — Inventory actions are lost on reload (persistence gap visible to the player)
- UX-P2-001 (P2) — Pinch-zoom is disabled (viewport maximumScale=1, userScalable=false)
- ARCH-P3-001 (P3) — AdventureScreen mutates a state object in place instead of returning a new one
- CHAIN-P3-001 (P3) — Exploit-chain surface is limited to save import; residual risk is client respawn
- CI-P3-001 (P3) — `next lint` is deprecated and will be removed in Next.js 16
- DATA-P3-001 (P3) — applyAdventureResult mutates item objects shared with the input inventory
- DET-P3-001 (P3) — [SEC] gitleaks not installed (secret scan skipped)
- DOC-P3-001 (P3) — README quality-gate command omits the build step used by CI
- EVOL-P3-001 (P3) — No feature-flag or plugin boundary for content/feature evolution
- HYGIENE-P3-001 (P3) — Vendored prompt pack dominates the repository tree
- HYGIENE-P3-002 (P3) — No .editorconfig; line/format policy is split across tools
- INFRA-P3-001 (P3) — Documented release/CI controls drift from the live repository configuration
- IR-P3-001 (P3) — No incident-response runbook or tabletop exercise recorded
- MOB-P3-001 (P3) — Manifest relies on SVG icons flagged maskable; no PNG/apple-touch fallback
- MOB-P3-002 (P3) — Service worker caches all runtime responses without a storage budget
- OBS-P3-001 (P3) — Client errors are only logged locally; no production error sink is wired
- PERF-P3-001 (P3) — Install-prompt detection polls on a 1s interval
- PRIV-P3-001 (P3) — No in-app privacy notice or data-management surface
- RES-P3-001 (P3) — Service worker caches every successful same-origin GET with no bound or eviction policy
- RES-P3-002 (P3) — No automated backup of the browser-local save
- SBOM-P3-001 (P3) — No license policy and no committed SBOM artifact
- SC-P3-001 (P3) — gitleaks runs with the default ruleset; no reviewed allowlist file in-repo
- SEC-P3-001 (P3) — Guest id falls back to Math.random in non-secure contexts
- TEST-P3-001 (P3) — Coverage scope excludes components/ and app/; no E2E or accessibility automation
- USE-P3-001 (P3) — Selling an item has no confirmation step
- UX-P3-001 (P3) — Install prompt and offline banner can overlay content
